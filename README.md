## 桌面软件

### 📑笔记/知识管理

- **Obsidian**，目前主力知识管理工具，丰富的插件市场极大地拓展了 obsidian 的功能以及颜值，配合插件可以轻易实现云端笔记同步
	- **主题 | Border**，目前用过组美观的主题，类似 Feishu/Arc 的设计风格
	- **字体 | LXGW WenKai**，很优美的中文字体，看起来也很舒服
	- **插件 | Auto Link Title**，cv 链接到笔记中时自动将 link 文本部分转化为对应站点的 title
	- **插件 | Easy Typing**，输入内容时自动进行格式化操作，比如中英文字符自动添加空格等
	- **插件 | Emoji Shortcodes**，允许以 `:xxx:` 的形式输入 emoji
	- **插件 | Excalidraw**，允许创建 excalidraw 画板类型的笔记
	- **插件 | Iconsize**，可以为目录或文件更改显示的 icon 图标
	- **插件 | Linter**，自动格式化笔记内容，比如段落换行时自动键入两个换行符
	- **插件 | Novel word count**，统计并展示文档字数在底边栏和侧边栏
- **Notion**，功能丰富且完善的知识管理工具，也支持协作共享，问题是只能在线使用且比较“重”，但是在更纯粹的文本编辑这方面要比 obsidian 强上一档
- **Typora**，适合初学者的 markdown 编辑器，语法实时渲染功能可以很大程度上提升 markdown 编辑效率，问题是功能相对单一，我现在很少使用这款软件
- **WPS/Office**，传统办公类软件，只在必要时使用

### 🕹️编程开发

- **Visual Studio Code**，主力代码编辑器，配合插件很舒服，不过对于部分语言来说不如 Jetbrains 的 IDE 舒服
- **Jetbrains IDE**，各语言备选开发 IDE，生态丰富但用起来略微复杂，吃资源比较多
- **Trae**，主力 AI 代码编辑器，截至目前所有模型免费用
- **Cursor**，AI 代码编辑器，用的少（因为没开订阅），AI workflow 逻辑比另外两家更舒适
- **Windsurf**，像是弱化版的 Cursor，之前用的很多，后来逐渐转向 Trae

### 🎭代理工具

- **Clash Verge**，代理工具，日常桌面使用
- **V 2 ray/V 2 rayA**，代理工具，会部署在国内服务器
- **ProxyChains**，命令行代理工具，用起来很方便

### 🌐浏览器

- **Microsoft Edge**，目前主力浏览器，相比 chrome 有着更优雅的 UI，并支持侧边栏
- **Thorium**，魔改后的 chrome，更低的内存占用和更高的性能，使用频率仅次于 edge
- **Google Chrome**，目前仅在渗透测试时使用
	- **FindSomething**，寻找页面中的泄露信息和 API
	- **ProxySwitchyOmega (V 3)**，代理插件
	- **Source Detector**，检测页面是否有 SouceMap 泄露
	- **Wappalyzer**，根据指纹探测站点技术栈
	- **Sourcegraph**，代码搜索插件
- **Arc**，有段时间非常火爆的浏览器，个人体验还行，对我来说没什么迁移的必要，很少使用
- **夸克**，手机上使用，解压功能和拍照搜题还是蛮方便的

### 📦虚拟机

- **Vmware Workstation**，主力虚拟机管理软件
- **VirtualBox**，用过一段时间的虚拟机管理软件，比 Vmware 轻量，但牺牲了部分性能

### 📮终端/SSH 客户端工具

- **Warp**，智能终端管理工具，响应速度很快，主力使用，有 AI 功能但我会关掉（消耗本地资源）
- **Windows Terminal**，轻量级终端管理工具，还好但用得少
- **Termius**，SSH 客户端工具，我也会当本地终端来中，在 SSH 管理这块很好用

## 安卓软件

### 👀聊天通信

- **Wechat**，与日常生活狠狠绑定了
- **QQ**，当前社交主战场
- **DingTalk**，学校指定组织交流软件，安恒办公交流软件，虽然觉得依托但是离不开

- **网易邮箱大师**，主要用来收发邮件

### 🧑‍🤝‍🧑社交媒体

- **Twitter/X**，目前主要使用的社交媒体，用户丰富，用来搜刮各类资源，算是半个朋友圈
- **小红书**，适合在特定领域搜索资料，比如旅游社交外貌运动等，也是我目前主要在运营的社交媒体，主要做资源分享，截止本文成稿约 1 k 粉
